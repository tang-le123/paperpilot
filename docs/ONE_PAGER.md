# PaperPilot 项目一页纸

## 一句话

**一个面向科研阅读的“可验证引用”RAG 助手：不只生成答案，还检查每条引用是否真的支持结论。**

## 问题

普通论文问答机器人有三个问题：

1. 所有问题都走同一条 RAG 链路；
2. 引用页码可能对，但原文不支持这句话；
3. 没有评测，无法判断回答是否可信。

## 方案

```text
上传论文
→ 章节感知解析
→ BM25 + bge-m3 + RRF + Cross-Encoder
→ 6 路自适应路由
→ DeepSeek 生成
→ 引用支持校验
→ 低支持率自动拒答
```

### 6 路路由

```text
内容问答 / 论文对比 / 创新点 / 术语解释 / 总结 / 条件不足
```

### 引用校验

```text
yes      支持
partial  部分支持
no       不支持 → 删除引用
低于阈值 → 不展示完整答案
```

## 结果

| 指标 | 结果 |
|---|---|
| 论文 | 14 篇（10 篇 arXiv + 中文论文 + 样例） |
| 评测 | 60 条 |
| 原始评测 | 30/30（标准过宽） |
| v1 门控 | 12/30，支持率 0.494 |
| v2 严格门控 @0.50 | 10/30，支持率 0.361，抑制率 66.7% |
| v2 门控 @0.35 | 15/30，支持率 0.370，抑制率 46.7% |
| 人工复核 | 30 条，完全一致 80% |
| 加权一致率 | 88.33% |
| Verifier 回归 | 6/6 |
| 测试 | 9 passed |

> v2 @0.50 只有 10/30，降到 0.35 后 15/30；不是“变准了”，而是减少抑制。真正问题是检索证据和 claim 级校验不足。
